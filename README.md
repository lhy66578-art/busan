# 🏪 부산광역시 착한가격업소 종류별 현황 분석

부산광역시 착한가격업소 공공데이터(`부산 착한가격업소 조회.csv`)를 바탕으로 **업소 종류(`업소구분`)별 등록 현황을 막대그래프로 시각화**하고, **원하는 업소 종류를 선택해 상세 업소 목록을 조회**할 수 있는 Streamlit 웹 애플리케이션입니다.

- **작성자**: 이하연 (불어불문학과, 202602173)

---

## 📌 주요 기능
1. **데이터 불러오기 및 전처리**: CSV 인코딩(`UTF-8` / `CP949`) 자동 처리, 결측치 정리, 중복 업체 제거, `소개` 열의 HTML 태그 제거
2. **요약 지표(KPI) 카드**: 전체 착한가격업소 수, 최다 등록 업종, 주차 가능 업소 수 표시
3. **업소 종류별 막대그래프**: 업소 구분(`음식점`, `이미용`, `목욕`, `기타`)별 업소 수 비교 시각화
4. **업소 종류 선택 및 상세 목록 조회**: 드롭다운 메뉴로 업소 종류를 선택하고 업소명·지역 키워드로 검색하여 상세 정보 확인

## 🚀 실행 방법

1. 필요한 라이브러리를 설치합니다.
   ```bash
   pip install -r requirements.txt
   ```

2. 스트림릿 앱을 실행합니다.
   - 팀 전체 앱에서 실행할 때:
     ```bash
     streamlit run app.py
     ```
   - 해당 페이지만 단독으로 확인할 때:
     ```bash
     streamlit run pages/1_good_price.py
     ```
